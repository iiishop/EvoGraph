# EvoGraph 工作台视觉方向

采用 frontend-design 和 ui-ux-pro-max。设计系统首次误匹配建筑作品集；重试 software developer dashboard 后，开发工具字体与对比建议适用，文档站首页布局不适用，不采用该布局。

核心是图工作台：侧边栏保持安静，连续画布占主区域，底部输入始终可用。源码现状与设计版本可切换，选中组件才展开证据。技术栈、决策、搜索依据按需展开。参考 Archify 的 Evidence Console、语义颜色、来源与版本维护，不声称实现其全部分析能力。

基础色：纸白 #f6f8fc，墨蓝 #20324b，弱文本 #53647b，操作蓝 #355ad6，源码青 #087e91，决策紫 #7751c4。组件角色颜色由 architectureRoles 单点维护，配合文字标识。

系统 Segoe UI / 微软雅黑用于正文，Consolas 用于源码；不依赖网络字体。正文 14–16px，紧凑标签 12px。主要操作高 44px，有清晰键盘焦点。动效只用于聚焦、更新与用户触发的展开，尊重 reduced-motion。

```
项目栏 | 架构标题 / 源码与设计版本
       | 搜索 / 关系范围 / 角色图例
       |     连续画布       | 选中组件依据
       | 技术选型、决策、网页依据（折叠）
       | Agent 输入、附件、追问
```

审查：去掉卡片网格与装饰性标签，让系统关系成为视觉主角。端口固定左入右出，架构边独立实现，使用 Vue Flow 实际端点而非假设布局坐标。
