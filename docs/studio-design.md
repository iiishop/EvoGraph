# EvoGraph 工作台调整

以任务流转为中心：条件检查 → 领取与制作 → 外部验收 → 完成并释放。
详情使用流程、范围与设计、记录三个层级，操作随状态变化，只保留当前主操作。

设计令牌：画布 #f3f5f6、纸面 #ffffff、正文 #243746、次级文字 #596a77、
操作色 #365e73、边界 #d6dfe4。Segoe UI / Microsoft YaHei 用于界面，
Consolas 仅用于路径与源代码；12 / 14 / 18 / 24 像素字阶，4 / 8 / 16 / 24 间距。

布局：左侧项目目录 | 中央图工作台 | 右侧任务流程；底部复用提问与建议输入。
架构以当前版本为默认，历史用可横向浏览的版本轨道；源码现状单列。

审视：不采用检索结果中不适合桌面工具的营销漏斗、装饰性渐变和海报字体。
采用 Productivity Tool 的扁平层级、功能色、操作反馈，任务卡像可领取的工作条目。
通知只说明真实发生的更新，底部进入，五秒退出，动画尊重减少动态效果设置。

UML 遵循 uml-style.md：PlantUML、矩形包、折线、关键成员和中文 note。
此规范不改变里程碑图的左右连接点与弧线。
